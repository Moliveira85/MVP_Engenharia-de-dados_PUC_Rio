# Ambiente

# 01. Configuração do Ambiente de Nuvem

Esta pasta reúne as evidências de provisionamento e configuração da infraestrutura de dados em nuvem utilizada para o desenvolvimento e a execução do pipeline.

### Componentes Evidenciados
- Workspace do Databricks configurado e operacional.
- Cluster de processamento Apache Spark provisionado para computação distribuída.
- Metastore e Unity Catalog habilitados (`workspace.default`).
- Storage de arquivos brutos e artefatos configurado via Databricks Volumes (`treinos_trainingpeaks`).
