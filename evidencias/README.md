# Evidências do MVP

Esta pasta reúne as evidências visuais da execução do MVP desenvolvido no Databricks.

As evidências estão organizadas nas seguintes categorias:

- Ambiente e notebooks;
- Tabelas e catálogo de dados;
- Execução do pipeline;
- Qualidade dos dados;
- Análise final;
- Resultados gerados.

Os screenshots foram revisados para evitar a exposição de dados pessoais, clínicos ou credenciais.
